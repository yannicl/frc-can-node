# Technical Documentation

These documents describe the circuits shown in the [v1 schematic](../hardware/schematic_v1.png). The board has been prototyped and checked. The documents serve as a reference to the circuit implementation; component limits remain subject to the selected parts' datasheets and the board's operating conditions.

- [Input protection](input-protection.md) — fuse, transient suppression, and reverse-polarity stage
- [5 V buck converter](buck-converter.md) — LMR14006XDDCR power stage and support components
- [CAN bus interface](can-interface.md) — transceiver, signal connections, protection, and optional termination
